# Research and design decisions

Researched 2026-10-06 (America/El_Salvador). No proprietary Roll Limitless material was used.

1. **[Santroller firmware](https://github.com/Santroller/Santroller)**, pinned commit `272bae8d28e17e9886e73344adeb8788a062eef4`: inspected `include/hid_reports.h`, `include/protocols/ps3.hpp`, `src/emulation/usb/ps3_device.cpp`, `src/emulation/usb/hid_device.cpp`, `src/mappings/rock_band_mappings.cpp`, gamepad hat conversion and USB identity constants. GPLv3 allows a GPLv3 derivative. This project's focused Pico SDK/TinyUSB architecture retains the established PS3 instrument wire protocol while avoiding unrelated configurator/protobuf/multi-console dependencies. This reduces runtime and build scope; it is not a full Santroller build.
2. **[Santroller Configurator](https://github.com/mat1jaczyyy/SantrollerConfigurator)** and **[Santroller drum guide](https://santroller.com/wiring_guides/drum.html)**: used to establish RP2040/PS3/drum and Pro support and the broader configuration model. This adapter's input is already digital MIDI, so piezo threshold/multiplexer wiring from the guide is not applicable. No configurator binary or runtime configuration protocol is included.
3. **[Santroller issue #17](https://github.com/Santroller/Santroller/issues/17)**: reported missing PS3 drum hits with Wii Band Hero input in July 2023. Closed with the “fixed in new firmware” label. The [issue comments API](https://api.github.com/repos/Santroller/Santroller/issues/17/comments) contains the maintainer's January 6, 2024 reply linking the fix to **[v10.0.1](https://github.com/Santroller/Santroller/releases/tag/v10.0.1)**. The discussion does not isolate one root-cause patch. We use the current post-v10 protocol implementation, including proper hat conversion and cymbal conflict handling; we do not claim to have proven the same historical defect impossible on hardware. Our input queue and transfer-completion timing are new code with dedicated tests, not an inferred copy of an unidentified fix.
4. **[ConsoleMods PS3XPAD](https://consolemods.org/wiki/PS3:PS3XPAD)**: background only. That plugin maps devices on modified systems; it is not evidence that arbitrary HID IDs work on a retail PS3. No plugin/config file from it is included or required. The native instrument identity comes from Santroller instead.
5. **[Alesis Nitro Drum Module User Guide v1.2](https://www.alesis.com/rscdn/1886/documents/Nitro%20Drum%20Module%20-%20User%20Guide%20-%20v1.2.pdf)**: appendix p38 supplies the default note numbers; the MIDI/settings sections establish configurable assignments and external MIDI operation. MIDI DIN transports events, not audio. Actual saved kit note assignments must be inspected; factory defaults are not assumed immutable. Pedal 44/splash 21 are optional musical events and ignored for gameplay by default.
6. **[Pico SDK 2.2.0](https://github.com/raspberrypi/pico-sdk/tree/2.2.0)**, **[TinyUSB](https://github.com/hathach/tinyusb/tree/86ad6e56c1700e85f1c5678607a762cfe3aa2f47)** and **[picotool 2.2.0](https://github.com/raspberrypi/picotool/tree/2.2.0)**: inspected the actual locked UART, queue, HID transfer/control callback and RP2040 build code. TinyUSB's IN completion/failure callbacks are the timing authority. Official picotool creates UF2, and the independent artifact audit checks conversion.
7. **[MIDI Association CA-033](https://midi.org/wp-content/uploads/wpforo/default_attachments/1709416667-ca33-MIDI-10-Electrical-Specification-Update.pdf)**: establishes input isolation, 220Ω input series resistor, diode polarity, ground isolation and 31.25kbaud signaling. The [manufacturer-origin Vishay 6N138/139 datasheet](https://www.mouser.com/datasheet/2/427/VSMIS13666_1-2572929.pdf) supplies optocoupler pinout and supply/output characteristics. The 3.3V pull-up/5V optocoupler split protects RP2040 GPIO. R2/R3 speed and level margins still require measurement on the selected part.

## Evidence boundaries

Protocol identities, offsets and descriptor bytes above are source-backed. Successful stock-PS3 recognition is the project's intended outcome, **not yet an observed result**. The exact game versions, polling/sampling tolerance, Pro combinations, menu navigation and electrical performance must pass `ps3-test-plan.md`. No console modification is proposed as a remedy if a test fails.
